# dmos

Graph equations, then play them — one at a time, or merged as a mix.

- **Chord** — each visible equation is its own voice.
- **Blend** — equations are added into one curve, then that mix is played.
- **Tune** — height is pitch.
- **Timbre** — the curve becomes a looping waveform.

Click **▶** on a mix to load and play it. Click **+** to stack those equations onto whatever you already have. **Import JSON** / **Export mix** share presets as files in `public/presets`.

```bash
npm install
npm run dev
```

Type `sin(x)`, add another equation, then hit Play mix. Space plays, drag pans, scroll zooms.
